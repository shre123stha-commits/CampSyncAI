# Screenshots

Placeholders for the images referenced by the main README and `DEMO.md`.
Capture these from a running instance — they are not committed as binaries so
the repository stays small.

Recommended captures, at a browser width of ~1400px:

| Filename | What to show |
|---|---|
| `01-login.png` | Sign-in page, including the "we never ask for your university password" banner |
| `02-dashboard.png` | Task list with priority colours, days remaining, and one completed task |
| `03-sources.png` | Connect accounts page with a calendar feed connected |
| `04-plan.png` | A weekly timed plan with sessions in real free slots |
| `05-feedback.png` | The feedback box open with a note typed in |
| `06-degraded.png` | The honest warning when a source or the LLM is unavailable |

To capture: run the app, sign in as a demo student with a warm cache, and use
your browser's built-in screenshot tool. Crop to the content area.

`06-degraded.png` is worth including deliberately — showing the failure state
as a designed experience rather than a crash is a strong point in a review.
